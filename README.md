# PrivacyPolicy

各应用的隐私政策页面，通过 GitHub Pages 托管：<https://marvin517.github.io/PrivacyPolicy/>

| 应用 | 路径 | 地址 |
|---|---|---|
| Line Go（一线牵） | `linego/` | https://marvin517.github.io/PrivacyPolicy/linego/ |
| Line Go（English） | `linego/en.html` | https://marvin517.github.io/PrivacyPolicy/linego/en.html |
| Kitchen Tower Defense | `index.html`、`root/` | https://marvin517.github.io/PrivacyPolicy/ |

## 维护说明

- 每个应用一个目录，`index.html` 为中文版，`en.html` 为英文版（如提供）。
- 页面为纯静态单文件（CSS 内联），无构建步骤，推送到 `main` 分支即自动发布。
- 内容变更时请同步更新页面顶部的「更新日期 / 生效日期」与底部「版本记录」表。
- 新增应用：复制 `linego/` 目录，替换应用名、SDK 清单等与产品实际行为相关的部分。
