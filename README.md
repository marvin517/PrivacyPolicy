## 维护说明

- 顶层 `index.html` 是 Marvin 的独立游戏开发者主页（深色单文件、无构建步骤），页面底部与导航内保留全部应用的隐私政策入口，供商店审核直达。
- 每个应用一个目录；新增应用：复制 `linego/` 目录，替换应用名、SDK 清单等与产品实际行为相关的部分，并在顶层主页「隐私政策」区块加入口。
- `index.html` 为中文版，`en.html` 为英文版（如提供）；纯静态单文件（CSS 内联），无构建步骤，推送到 `main` 分支即自动发布。
- 内容变更时请同步更新页面顶部的「更新日期 / 生效日期」与底部「版本记录」表。
- 新增应用：复制 `linego/` 目录，替换应用名、SDK 清单等与产品实际行为相关的部分，并在顶层索引页加入口。
